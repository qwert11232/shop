# 🎨 ТЕХНОЛАБ — дизайн-система

Направление: **швейцарская типографика с яблочной школой** — белое полотно, чёрная
структура, единственный сигнальный красный. Дизайн держится на сетке, типографике
и воздухе, а не на эффектах.

## Правило трёх цветов

Палитра закрыта. Четвёртого цвета нет, включая фоновые заливки, тени и свечения.

| Токен | Значение | Роль |
| --- | --- | --- |
| `paper` | `#ffffff` | фон всех экранов и поверхностей |
| `ink` | `#0a0a0a` | текст, линии-разделители, инверсные плашки |
| `signal` | `#e00b20` | цена, главное действие, выбранное/фокус, ошибки |

Служебные оттенки — не цвета, а уровни чёрного на белом:

| Токен | Значение | Где | Контраст |
| --- | --- | --- | --- |
| `ink-2` | `#565656` | вторичный текст, описания | 4.54:1 — проходит AA |
| `ink-3` | `#8a8a8a` | только подписи ≥ 14px и плейсхолдеры | 3.03:1 |
| `rule` | `#e4e4e4` | рамки карточек, разделители | — |
| `signal-dim` | `#fbe7e9` | фон не используется как декор; оставлен для disabled | — |

**Дисциплина красного.** Сигнал появляется не больше двух раз на экран: цена и главная
кнопка. Красная заливка на всю ширину — только `.btn-primary` и промо-плашка ошибки.
Красный никогда не используется для декора, иконок и разделителей произвольной длины.

## Типографика

Одна гарнитура — **Manrope** (400/500/600/700, кириллица). Вторая не нужна: различие
делается кеглем, весом и трекингом, а не сменой шрифта.

| Роль | Класс | Размер | Вес | Трекинг |
| --- | --- | --- | --- | --- |
| Цена на витрине | `.t-price-lg` | 18px | 800 | −0.02em, `tabular-nums` |
| Цена в списке | `.t-price` | 14.5px | 800 | −0.015em, `tabular-nums` |
| Заголовок секции | `.t-section` | 15px | 700 | −0.02em |
| Название товара | `.t-title` | 13.5px | 650 | −0.005em |
| Основной текст | `.t-body` | 13px | 500 | 0 |
| Бренд, служебное | `.t-brand` | 10.5px | 800 | 0.07em, uppercase, `ink-3` |
| Метка поля | `.label` / `.t-label` | 10.5–11px | 750 | 0.06em, uppercase |

Шкала — решение, а не побочный эффект: **цена всегда крупнее названия**, бренд
всегда мельче названия и капсом, тело текста — только для чтения. Проверяется
в `npm run check:shop` (кегль `.t-price-lg` ≥ 17px, наличие всех классов).

Правила: заголовки — `leading-snug`, описания — `leading-relaxed`, абзацы выключены
по левому краю, `max-w-prose` не нужен (мобильная колонка ≤ 448px).

## Иконки

Отдельный набор SVG в `src/components/icons.tsx`. Условия, которые нельзя нарушать:

- один стиль: контурный (`fill="none"`), `stroke-width: 1.75`, `round` соединения;
- цвет только `currentColor` — иконка не вводит четвёртый цвет;
- размеры 14/15/16/17/18/20/26px, по умолчанию 20;
- декоративные иконки — `aria-hidden`, у кнопок-иконок обязателен `aria-label`;
- эмодзи в интерфейсе запрещены. Исключение — текст заявки, уходящий в Telegram:
  там эмодзи работают как разметка сообщения, а не как иконки UI.

## Геометрия

Радиус — ступени по смыслу, не одно значение на всё:

| Элемент | Радиус |
| --- | --- |
| Кнопки, инпуты, чипы | 10px (`--radius-control`) |
| Карточки, списки, блоки | 14px (`--radius-card`) |
| Модалка снизу | 18px сверху (`--radius-sheet`) |

Сетка отступов — 4px: 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40. Внутренний отступ меньше
внешнего (принцип близости). Тени отсутствуют полностью: глубина передаётся рамкой
и инверсией.

## Компоненты (`globals.css`)

| Класс | Описание |
| --- | --- |
| `.btn-primary` | единственная красная плашка на экран, белый текст, hover `#b80918`, disabled `#f3c6ca` |
| `.btn-ghost` | чёрная рамка 1px на белом, при hover инвертируется в чёрный |
| `.card` | карточка товара: рамка `rule`, при hover рамка чёрная, без сдвигов и теней |
| `.chip` | категория/таб: контурный, выбранный — чёрная заливка с белым текстом |
| `.icon-btn` | кнопка-иконка 32×32, hover — серый `#f2f2f2` |
| `.photo-frame` | подложка фото: мягкий градиент `#fbfbfa → #f0efeb`, кадр заполняет плитку. Единая рамка для студийных и тёмных кадров |
| `.shelf` / `.shelf-cell` | сетка каталога: линии `1px` через `gap` вместо рамки у каждой карточки; цена прижата к низу ячейки |
| `.spotlight` | акцентный блок первого экрана: кадр вписан целиком, белая плашка «название + цена» поверх |
| `.tab` | категория-таб: подчёркивание, активный — красный. Заменил плашку `.chip` в ленте категорий |
| `.empty` / `.empty-icon` | пустое состояние: иконка в круге, объяснение и действие вместо рамки с текстом |
| `.edge-fade` | затухание по правому краю горизонтальной ленты — видно, что список продолжается |
| `.app-header` | шапка экрана: липкая, разделитель `rule`, а не `ink` |

**Слои.** Все компонентные классы лежат в `@layer components`. Без слоя
`.input { padding }` перебивал `pl-9` из Tailwind по порядку в бандле —
иконка поиска налезала на плейсхолдер. Проверяется в `check:shop`.
| `.input` / `.label` | поля: рамка `rule` → чёрная на focus, `aria-invalid` красит в signal |
| `.price` | цена: signal + `tabular-nums` |
| `.meta` | подпись 12px, `ink-2` |
| `.sheet` / `.sheet-backdrop` | модалка снизу как нативный sheet Telegram, тень заменена чёрной линией сверху |

## Экраны

Навигация — четыре таба внизу (Каталог, Избранное, Корзина, Профиль) плюс экраны
второго уровня: товар, оформление, сравнение. Переходы без роутера — состояние
в `ShopApp`, поэтому корзина и избранное не перезагружаются.

1. **Каталог** — чёрная линия под шапкой (без размытия), поиск на всю ширину,
   горизонтальные чипы категорий, строка «сортировка — N шт. — фильтры».
   Сетка 2 колонки; фото `object-contain` на `#f6f6f6` — разные по пропорциям
   снимки не обрезаются и не «прыгают». Кнопка сравнения — в углу карточки,
   чтобы не мешать переходу в товар.
2. **Фильтры** — раскрывающаяся панель в рамке: бренды и характеристики чипами
   со счётчиками, цена — четырьмя готовыми диапазонами (без клавиатуры в модалке),
   счётчик активных условий и «Сбросить всё».
3. **Карточка товара** — галерея со снапом и точками, бренд, название, цена
   (пересчитывается при выборе варианта), рейтинг звёздами, варианты чипами
   с надбавкой «+12 000 ₽», пара кнопок «В корзину» / «Сравнить»,
   табы «Описание / Характеристики / Отзывы», блок «С этим товаром покупают»
   горизонтальной лентой. Отзыв пишется прямо в табе: звёзды + текст.
4. **Корзина** — строки с миниатюрой, вариантом и степпером; удаление свайпом
   влево (порог 64 px) и крестиком как запас для десктопа; итог в чёрной рамке.
5. **Оформление** — имя из Telegram, телефон один раз, ползунок бонусов
   (не больше 30% и не больше баланса), комментарий, состав заказа.
   После отправки — экран с галочкой в чёрном круге и суммой бонусов.
6. **Профиль** — аватар-инициал, чёрная карта лояльности (баланс, 3%, реферальный
   код), ввод кода друга, телефон, табы «Заказы / Бонусы».
   Заказ — карточка с прогрессом из четырёх шагов доставки, трек-номером и позициями.
7. **Сравнение** — таблица 2–3 моделей с закреплённой первой колонкой;
   красным подсвечено только объективно лучшее значение (память, камера, автономность).
8. **Админка `/admin`** — три таба с иконками (Товары, Категории, Заявки),
   формы в чёрной рамке, загрузка фото — зона с пунктирной рамкой,
   заявки — плотный список с комментарием, отмеченным красной линией слева.
9. **Бот** — те же экраны панели в Telegram; в карточке заявки первая строка
   кнопок — доставка («Дальше: Передан в доставку»), вторая — трек-номер и отмена.

## Состояния

| Состояние | Как выглядит |
| --- | --- |
| Загрузка каталога | скелетон из 4 карточек, без спиннеров |
| Пустая категория | рамка-плейсхолдер, иконка `ink-3`, текст «В этой категории пока нет позиций» |
| Пустые заявки | рамка-плейсхолдер «Заявок пока нет» |
| Ошибка загрузки | текст в красной рамке, без иконок-эмодзи |
| Ошибка отправки | красный текст под полем, поле получает `aria-invalid` |
| Пустая корзина / избранное | рамка-плейсхолдер и кнопка возврата в каталог |
| Ничего не нашлось | «Ничего не нашлось» + «Сбросить фильтры», а не пустой экран |
| Нет Telegram | профиль объясняет, что кабинет работает внутри Telegram, и предлагает каталог |
| Сборка заказа | прогресс: чёрные шаги пройдены, красный — текущий, серые — впереди |
| Отменённый заказ | статус «Отменён» без прогресс-бара |
| Фокус клавиатурой | контур `2px signal` со смещением 2px на всех интерактивных элементах |

## Движение

- только `transform` и `opacity`, 120–220ms, `ease-out` на вход;
- `.screen-enter` — экран поднимается на 12px и проявляется при смене вкладки,
  `.toast-enter` — короткий подъём уведомления, `.fade-in` — панель фильтров;
- `HapticFeedback`: `light` на добавление в корзину, `selection` на чипы и табы,
  `success` после оформления и отзыва, `error` при отказе сервера; дребезг глушится 60 мс;
- hover не двигает сетку: меняется цвет рамки или заливки;
- `prefers-reduced-motion: reduce` глушит все анимации глобально (блок в `globals.css`);
- бесконечных анимаций нет.

## Чем этот дизайн отличается от прежнего

Прежняя версия — тёмная «лаборатория» с acid-лаймом, фиолетовым свечением, Unbounded
и эмодзи-иконками. Это ровно тот набор, который считывается как сгенерированный
по умолчанию: near-black фон + один неоновый акцент, градиентные блики, скругления
всех элементов одним радиусом. Новая версия сознательно убирает свечения, градиенты,
вторую гарнитуру и эмодзи и оставляет три цвета, сетку и один сигнал.

- [ ] Нет теней, градиентов, `backdrop-blur`.
- [ ] Радиусы соответствуют ступеням, а не одному значению.

## Новинки, карусель кадров и скидка (2026-11-07)

**Лента новинок** (`Новое в магазине`) стоит на первом экране каталога и только
там: внутри раздела покупатель уже сузил выбор категорией, и лента «из другого»
там мешает. Шесть свежих позиций по `created_at`, горизонтальный скролл с
затуханием по краю (`.edge-fade`).

**Карусель кадров** (`src/components/ui/PhotoCarousel.tsx`) — в каждой карточке
сетки: нативные `overflow-x-auto` + `snap`, точки и счётчик `2/4`. Лежит внутри
кнопки «открыть товар», поэтому свайп отслеживается по сдвигу (> 8 px) и гасит
клик через `onClickCapture` — листание не открывает карточку.

**Скидка.** Модель данных: `products.old_price` — зачёркнутая цена, `price` —
сколько платит клиент. Корзина, заказы и бонусы считаются по `price`, поэтому
скидка не может «потеряться» в момент оформления. На витрине процент — бейджем
поверх фото (`.discount-badge`, инверсный `ink`), а не третьим числом в строке
цены: на карточке шириной 171 px «цена + старая цена + процент» переносились и
рвали выравнивание сетки.

Владелец задаёт скидку в боте: карточка товара → «Скидка» → процент (`10`)
или старая цена (`109990`), `0` снимает. Предел — 50%.

**Фото с прилавка.** `public/shop-photos/` — живые кадры (товар на столе, рука
продавца, витрина), по три на товар, в галерее вместе со студийным. Сборка
сжимает их в WebP тем же `scripts/optimize-images.ts` (обе папки).
Сид добавляет новые кадры к существующим товарам, но **не подмешивает демо-фото,
если владелец загрузил свои** (`/uploads/`) — проверяется в `check:shop`.
