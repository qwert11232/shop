# 🎨 ТЕХНОЛАБ — дизайн-система

Концепция: **«тёмная лаборатория»** — техника в тёмной «витрине-лаборатории» с acid-лаймовым
свечением. Название ТЕХНОЛАБ обыгрывается сеткой фона и «живым» индикатором (glow-dot).

## Палитра

| Токен | Значение | Где применяется |
| --- | --- | --- |
| `bg` | `#07090c` | фон приложения |
| `surface` / `surface2` | `#0e1218` / `#141a23` | карточки, модалки, инпуты |
| `line` | `#1f2733` | границы карточек и чипов |
| `text` / `muted` | `#f2f5f7` / `#8a94a6` | основной текст / вторичный |
| `acid` | `#c6f32e` | **фирменный акцент**: цены, CTA, активные чипы, свечение |
| `violet` | `#7c5cff` | вторичный акцент, промо-полоса |
| `danger` | `#ff5c6c` | ошибки |

Фон: радиальные свечения (violet сверху справа, acid слева) + тонкая сетка 44×44 px —
«лабораторная» подложка.

## Типографика

- **Unbounded** (500/700/800, кириллица) — логотип, заголовки, цены (`price-tag` со свечением).
- **Manrope** (400–800, кириллица) — основной текст, инпуты, подписи.
- Подключены через `@fontsource/*` (локально, без внешних запросов).

## Компоненты (globals.css)

- `.btn-acid` — главная CTA: acid-фон, тёмный текст, свечение при hover, `scale(0.97)` при нажатии.
- `.btn-ghost` — вторичная кнопка (граница, hover → acid).
- `.card` — карточка товара: градиент surface2→surface, радиус 18px, при нажатии сжимается и
  подсвечивается acid-границей.
- `.chip` — категории: «пилюли», активная — acid.
- `.sheet` + `.sheet-backdrop` — модалка снизу (как нативный sheet Telegram), анимация `slideUp`.
- `.input` / `.label` — поля форм админки.
- `.price-tag` — цена шрифтом Unbounded + acid-свечение.
- `.glow-dot` — «живой» индикатор в шапке.

## Экраны

1. **Витрина `/`** — sticky-шапка (логотип + статус «онлайн» + вход ⚙️), промо-полоса,
   горизонтальные чипы категорий, сетка товаров 2 колонки (фото квадратом, название, цена),
   футер. Тап по карточке → sheet с фото, описанием, полем комментария и CTA «Оформить заказ».
   После отправки — экран успеха ✅ с текстом заявки (что ушло в группу).
2. **Админка `/admin`** — три таба: 📦 Товары (форма публикации + список), 🗂 Категории
   (создание с эмодзи-иконкой), 🛒 Заявки (лента с фото товара, ценой, клиентом, комментарием).

## Микродетали

- Тап-отклик карточек (scale), плавные анимации sheet/popIn.
- `line-clamp-2` для названий, `truncate` в админке.
- Адаптация под Telegram: `maximumScale=1`, `themeColor=#07090c`, `tg.expand()`.
- Пустые состояния («В этой категории пока пусто», «Заявок пока нет») — осмысленные тексты.
