# 🤖 ТЕХНОЛАБ — настройка Telegram (пошагово)

## 1. Бот

1. В Telegram напишите **@BotFather** → `/newbot` → задайте имя (например, `ТЕХНОЛАБ`) и username (`...bot`).
2. Сохраните **токен** → в `.env` проекта: `BOT_TOKEN=...`.

## 2. Мини-приложение (WebApp)

1. У задеплоенного сайта должен быть **HTTPS-адрес** (Vercel даёт автоматически) → `WEBAPP_URL=https://ваш-домен`.
2. В @BotFather: `/newapp` (или `/setmenubutton` для существующего бота) → выберите бота →
   загрузите иконку (можно `/brand/logo.png`) → укажите **URL мини-приложения** = `WEBAPP_URL`.
3. Разрешите WebApp: `/setdomain` → выберите бота → домен приложения.

## 3. Группа и заявки

1. Создайте группу, добавьте туда бота и **сделайте его администратором** (право отправлять сообщения).
2. Узнайте `chat_id` группы: добавьте в группу **@userinfobot** (или напишите боту `@getidbot`) —
   скопируйте ID (обычно отрицательное число, например `-100123456789`) → `GROUP_CHAT_ID=...`.
3. Прикрепите к группе кнопку запуска приложения: в @BotFather `/setmenubutton` либо в настройках
   группы — «Привязать приложение». Участники открывают витрину прямо из группы.

## 4. Владелец и админка

1. Узнайте свой Telegram ID: напишите боту `/start` или спросите **@userinfobot** → число.
2. Запишите в `.env`: `OWNER_TELEGRAM_ID=123456789`.
3. Откройте `https://ваш-домен/admin` из Telegram — все запросы подписываются initData,
   сервер сверяет HMAC и пропускает только владельца.

## 5. Проверка

- Откройте приложение из группы → каталог грузится.
- Оформите тестовую заявку → в группе появляется сообщение вида
  «🛒 Новая заявка — ТЕХНОЛАБ … 📦 Позиция: … 👤 …».
- В `/admin` → таб «Заявки» видит ту же заявку.

## Безопасность

- initData проверяется по HMAC-SHA256 на сервере (`src/lib/telegram.ts`), `auth_date` старше 24 ч — отклоняется.
- `ALLOW_DEV_NO_AUTH=1` работает **только локально** (`NODE_ENV !== production`) — на проде выключите.
- Секреты только в `.env`/хранилище секретов хостинга, никогда в репозитории.
