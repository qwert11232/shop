### Шаг 1: Запуск проекта ТЕХНОЛАБ (2026-11-04)
- Контекст: владелец хочет Telegram Mini App-магазин техники «ТЕХНОЛАБ»: витрина с категориями и товарами, заявка на товар уходит сообщением в группу; фото — Apple, приставки, бытовая техника.
- Решение: Next.js 15 + React 19 + Tailwind v4 + SQLite через better-sqlite3 (Prisma исключён: движки качаются с недоступного binaries.prisma.sh). Слой данных — src/lib/repo.ts, схема локально в src/lib/db.ts, для prod PostgreSQL — db-setup.sql. Страницы: `/` (каталог, sheet заказа), `/admin` (товары/категории/заявки). API: catalog, orders, admin/*. initData валидируется HMAC-SHA256, владелец — по OWNER_TELEGRAM_ID. Документы: docs/ARCHITECTURE.md, docs/DESIGN.md, docs/TELEGRAM-SETUP.md; бриф: .ai/PROMPTS/brief-2026-11-04-tekhnolab.md. Дизайн: тёмная «лаборатория», acid #C6F32E, шрифты Unbounded+Manrope. Фото 17 товаров в public/products/, логотип public/brand/logo.png. Скиллы развёрнуты из skills.txt.
- Альтернативы: Vite + отдельный backend — отклонено (один деплой Next.js проще); PostgreSQL локально — невозможно в песочнице.
- Риски: без BOT_TOKEN группа не получает сообщения (демо-режим показывает текст заявки); фото — сторонние, перед релизом заменить на свои.
- Проверка: `npm install`, `db:seed`, `typecheck`, `build`, dev-сервер + curl /api/catalog и /api/orders.

### Шаг 0: Инициализация каркаса памяти
- Контекст: репозиторий скопирован из универсального каркаса управления ИИ (`.ai/`);
  конкретный проект ещё не описан, стек и бизнес-логика неизвестны.
- Решение: каркас развёрнут как есть; структура `.ai/` (`MEMORY.md`, `RULES.md`, `skills.txt`,
  `PROMPTS/`, `DEPLOY/`, `ASSETS/`) и корневой `README.md` — инструкция для агентов.
- Альтернативы: держать инструкции в одном файле — отклонено: правила, брифы и память меняются
  с разной частотой, и в одном файле контекст раздувается.
- Риски: каркас без проектных значений бесполезен, пока разделы `[...]` не заполнены.
- Проверка: структура и ссылки между файлами сверены вручную; прикладной код отсутствует
  по определению — это шаблон.
